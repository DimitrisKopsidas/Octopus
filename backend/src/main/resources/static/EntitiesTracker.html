Architecture Notes

  • Course is the parent entity for Question.
  • Question is the parent entity for Answer.
  • CascadeType.ALL on Question -> Answer means answers are saved/deleted automatically with the question.
  • orphanRemoval = true removes answers from the database if removed from the list.
  • FetchType.LAZY delays loading related entities until accessed.
