Architecture Notes

  • Course is the parent entity for MulQuestion.
  • MulQuestion is the parent entity for MulAnswer.
  • CascadeType.ALL on MulQuestion -> MulAnswer means answers are saved/deleted automatically with the question.
  • orphanRemoval = true removes answers from the database if removed from the list.
  • FetchType.LAZY delays loading related entities until accessed.
